⚠️ Script SQL para o Supabase

Se a sincronização apresentar erros, acesse o SQL Editor do seu painel Supabase e execute este comando para criar a tabela e as permissões RLS:

create table if not exists public.pontos (
  id bigint generated by default as identity primary key,
  "linhaId" integer not null,
  toque text,
  titulo text,
  letra text,
  autor text,
  link text,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- Habilitar acesso público para leitura/escrita
alter table public.pontos enable row level security;
create policy "Acesso total publico" on public.pontos for all using (true) with check (true);
